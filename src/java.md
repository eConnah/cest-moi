# Java

I acquired over a year of Java experience during my first year of university.
Having already worked extensively with C#, transitioning to Java felt quite
natural due to their structural and syntactic similarities.

## Qubic

My first major Java project was a two-person collaboration to build _Qubic_, a
4x4x4 3D Tic-Tac-Toe game. We utilised Swing UI and JavaFX for the interface,
which includes a fully functional 3D render of the board. The game features both
a two-player mode (local, same-device only) and a single-player mode against
different custom opponent algorithms. It also automatically saves match data to
JSON, allowing players to watch replays of finished games.

## Stocked

For my second university project, I worked in a larger six-person team to
develop _Stocked_, a local kitchen inventory tracker built with Java 25 and
JavaFX. The application is designed to combat food waste by tracking ingredients
across your fridge, freezer, and cupboard.

We prioritised privacy by ensuring 100% local data persistence. We used Java
Object Serialization due to not being allowed external libraries (other than
JavaFX/Swing), and we maintained code quality with a strict JUnit 5 testing
suite.
