# C#

My journey with C# began in secondary school, where I gained around two years of
experience whilst studying for my AQA A-Level in Computer Science. For my
coursework, I developed a 2D platformer game using the Unity engine. As we
hadn't yet been taught proper version control with Git, the original source code
has unfortunately been lost to time.

I have also experimented briefly with Razor Pages whilst attempting to build a
tool for calculating fuel price splitting between friends, though I stopped
without getting too far since I decided to start learning Nix.

Whilst my coursework code is gone, you can browse the collection of my early C#
practice projects, ranging from simple sorting algorithms to console games like
Tic-Tac-Toe and Hangman, in my archived
[School-CSharp repository](https://github.com/eConnah/School-CSharp).
